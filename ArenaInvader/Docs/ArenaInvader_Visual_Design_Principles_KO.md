# Arena Invader 시각 디자인 철칙

작성일: 2026-06-23

이 문서는 현재 `Arena Invader`의 플레이 감각, 스프라이트 자산, UI 프레임, 전투/보드 구조를 기준으로 앞으로의 시각적 방향을 정리한 문서입니다.  
목표는 "무엇을 예쁘게 만들지"보다 "어떤 인상으로 일관되게 보여줄지"를 정하는 것입니다.

## 1. 시각 정체성 한줄 정의

`가벼운 캐주얼 판타지 보드 위에, 경쟁 정보가 또렷하게 보이는 전략 UI`

즉, 이 게임은 너무 무겁거나 사실적인 방향보다 다음의 조합이 잘 맞습니다.

- 친숙하고 읽기 쉬운 캐릭터/말 디자인
- 칸 효과와 전투 위험이 즉시 보이는 보드 표현
- 턴제 전략 게임에 맞는 명확한 정보 우선 UI
- `Baron` 등장과 전투 순간에는 강한 대비로 긴장감 강조

## 2. 전체 비주얼 방향

### 철칙 1. 기본은 밝고 선명하게, 위협 요소만 무겁게

평상시 화면은 캐주얼하고 밝아야 합니다.  
대신 전투, 위험 칸, `Baron`, 패배 직전 상태만 더 무겁고 강하게 보여야 합니다.

실천 기준:

- 일반 보드와 UI는 중간~고명도 톤을 기본으로 사용
- 위험 요소에는 어두운 배경보다 강한 대비색을 사용
- 화면 전체를 어둡게 만드는 대신, 위험 대상을 선명하게 띄우는 방식 우선

### 철칙 2. 보드는 장식보다 판독성이 먼저다

이 게임의 핵심은 "어디로 가는지" 읽는 것입니다.  
맵은 예쁘더라도 이동 경로와 이벤트 칸이 한눈에 읽혀야 합니다.

실천 기준:

- 길, 분기점, 목적 칸은 배경보다 명도 대비가 높아야 함
- 칸 유형은 색뿐 아니라 아이콘/프레임/표식으로도 구분
- 보드 장식은 경로 실루엣을 가리지 않아야 함

### 철칙 3. 말과 캐릭터는 귀엽되, 역할은 즉시 구분되어야 한다

현재 자산은 완전한 하드코어 전쟁 게임보다 캐주얼 경쟁 게임 쪽에 가깝습니다.  
이 장점을 살려, 플레이어 말은 친근해야 하지만 역할 구분은 매우 빨라야 합니다.

실천 기준:

- 공격형, 방어형, 이동형 말은 실루엣과 표정, 포인트 색으로 즉시 구분
- 팀 구분은 색 하나만이 아니라 깃발, 윤곽선, UI 배지로 중복 표현
- 캐릭터 초상은 감정과 상태가 잘 보이도록 단순 명확한 표정 유지

### 철칙 4. 전투 화면은 짧게 보이더라도 강하게 기억되어야 한다

전투는 플레이 루프 전체에서 순간 이벤트에 가깝지만, 감정적으로는 매우 중요합니다.

실천 기준:

- 전투 진입 시 배경 명도는 약간 낮추고 캐릭터 대비는 올림
- 공격, 피격, 피해 숫자는 한 박자 크게 보여줌
- 전투 UI는 정보보다 충돌의 인상을 먼저 전달하되, 피해량은 명확하게 남김

### 철칙 5. 정보 UI는 게임 세계관보다 플레이 판단을 우선한다

전략 게임의 UI는 분위기 소품이 아니라 판단 도구입니다.

실천 기준:

- HP, 돈, 공격력, 방어력, 턴 정보는 항상 빠르게 읽혀야 함
- 장식 프레임은 좋지만 텍스트 대비를 해치면 안 됨
- 숫자는 이미지 안에 숨기지 말고 또렷한 레이어로 분리

## 3. 색상 원칙

### 기본 팔레트 방향

- 베이스: 따뜻한 아이보리, 밝은 스톤, 옅은 청회색
- 보드 강조: 골드, 코랄, 틸, 선명한 블루
- 위험 신호: 크림슨, 주황-적색, 강한 자홍은 제한적으로 사용
- 오브젝트/보스: 보라-남색 계열보다는 붉은 자주 혹은 어두운 금속 톤 권장

### 색상 사용 철칙

- 좋은 효과는 밝고 환한 색
- 위험 효과는 포화도가 높은 경고색
- 중립 정보는 회색이 아니라 채도 낮은 컬러를 써서 화면 생기를 유지
- 한 화면에서 주인공 경쟁색은 2~3개만 강하게 유지

## 4. 형태와 프레임 원칙

### 철칙 1. 둥글지만 흐리지 않게

현재 UI 프레임 자산은 캐주얼한 인상에 잘 맞습니다.  
다만 모든 요소를 둥글고 말랑하게만 만들면 전략 정보가 약해집니다.

실천 기준:

- 버튼, 패널 외곽은 부드럽게
- 수치, 턴 순서, 선택 강조선은 각이 살아 있는 형태 허용
- 캐주얼함과 전략성을 동시에 주기 위해 "패널은 부드럽고 정보는 날카롭게" 구성

### 철칙 2. 선택 상태는 멀리서도 보여야 한다

말 선택, 이동 가능 상태, 턴 주체, 위험 목표는 시선이 짧게 스쳐도 보여야 합니다.

실천 기준:

- 선택된 말은 외곽선, 바닥 링, 상승 애니메이션 중 2개 이상 사용
- 현재 턴 플레이어는 이름 색만 바꾸지 말고 패널 구조 자체를 강조
- `Baron` 관련 이벤트는 별도 프레임 색과 카운트다운 배지 제공

## 5. 타이포그래피 원칙

이 프로젝트는 복잡한 세계관 서사보다 즉시 이해가 더 중요합니다.

실천 기준:

- 제목용 폰트는 개성 있어도 좋지만, 본문과 수치는 매우 읽기 쉬워야 함
- 한글 UI는 지나치게 장식적인 폰트보다 둥글고 선명한 폰트를 우선
- 데미지, HP, 턴 수, 코인 수치는 굵기 차이를 강하게 줘서 눈에 띄게 표시
- 텍스트 그림자나 외곽선은 장식보다 대비 확보용으로 사용

## 6. 애니메이션 원칙

### 철칙 1. 상호작용은 짧고 정확하게

턴제 게임은 조작이 반복되기 때문에, 애니메이션이 길어지면 곧 피로가 됩니다.

실천 기준:

- 버튼 반응, 선택 표시, 칸 강조는 짧고 선명하게
- 말 이동은 읽힐 정도의 속도는 유지하되 과하게 느리면 안 됨
- 전투 진입, 잡기, 업기, `Baron` 출현은 일반 액션보다 더 강하게

### 철칙 2. 중요한 사건만 크게 연출한다

모든 것을 화려하게 만들면 아무 것도 중요해 보이지 않습니다.

크게 연출할 대상:

- 적 말 잡기
- 업기 성공
- `Baron` 출현
- 전투 승패 확정
- 게임 종료

작게 처리할 대상:

- 일반 UI 열기/닫기
- 수치 갱신
- 단순 선택 변경

## 7. 이 게임에 특히 어울리는 시각 키워드

추천 키워드:

- `캐주얼 전략`
- `보드 위 결투`
- `밝은 긴장감`
- `아기자기한 경쟁`
- `명확한 판독성`
- `이벤트가 살아 있는 맵`

피해야 할 키워드:

- `과도한 다크 판타지`
- `리얼 전쟁 시뮬레이션`
- `모바일 방치형 번쩍임`
- `SF 네온 과포화`
- `텍스트보다 장식이 많은 UI`

## 8. 화면별 우선순위

### 메인/매치 설정

- 친근함
- 시작 기대감
- 캐릭터/모드 선택의 명확성

### 플레이 보드

- 현재 턴 판독
- 이동 경로 판독
- 위험/보상 칸 판독

### 전투

- 누가 때리고 누가 맞는지 즉시 이해
- 피해량 체감
- 승패 결과의 감정적 전달

### 결과 화면

- 승자 강조
- 살아남은 느낌
- 한 판이 끝났다는 명확한 보상감

## 9. 한줄 원칙

`Arena Invader`의 시각 디자인은 "귀엽고 밝게 시작해도, 중요한 순간에는 전략 게임답게 또렷하고 강하게 보여야 한다"를 지켜야 합니다.

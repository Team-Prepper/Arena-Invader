# _UNetPlay 테스트 체크리스트

작성일: 2026-06-23

## 기본 흐름

- [ ] 호스트가 방 생성 후 룸 설정 UI를 정상적으로 연다
- [ ] 클라이언트가 접속하면 플레이어 목록에 바로 반영된다
- [ ] 플레이어 이름 변경이 모든 참가자에게 동기화된다
- [ ] 캐릭터 변경이 모든 참가자에게 동기화된다
- [ ] `IsAI` 토글 값이 이름 변경 후에도 유지된다
- [ ] 2인 이상일 때만 매치 시작이 가능하다

## 턴 진행

- [ ] 호스트와 클라이언트가 각자 자기 캐릭터만 조작한다
- [ ] 턴 시작 UI가 현재 턴 플레이어에게만 자연스럽게 표시된다
- [ ] 주사위 결과가 모든 참가자 화면에서 동일하게 반영된다
- [ ] 말 이동 결과가 모든 참가자 화면에서 동일하게 반영된다
- [ ] 턴 종료 후 다음 플레이어로 정상 진행된다

## 인벤토리

- [ ] 상점 구매 후 아이템 목록이 모든 참가자 화면에서 동일하게 보인다
- [ ] 아이템 사용 후 아이템이 인벤토리에서 제거된다
- [ ] 아이템 사용 후 능력치/효과가 모든 참가자 화면에서 동일하게 반영된다
- [ ] 아이템 버리기 후 인벤토리와 플레이어 UI가 함께 갱신된다
- [ ] 인벤토리를 열어둔 다른 참가자 화면도 변경 후 즉시 갱신된다

## 전투/사망

- [ ] 전투 시작과 결과가 모든 참가자에게 동일하게 보인다
- [ ] 사망한 플레이어는 턴 진행 대상에서 제외된다
- [ ] 마지막 1명만 생존하면 결과 화면이 정상적으로 열린다

## 접속/종료

- [ ] 클라이언트 이탈 시 룸 플레이어 목록이 정상적으로 줄어든다
- [ ] 매치 종료 후 `Playground`, 턴 시스템, 준비 카운트가 초기화된다
- [ ] 같은 세션에서 다시 방을 열거나 재시작해도 이전 상태가 남지 않는다
